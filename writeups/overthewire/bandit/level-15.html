OverTheWire Bandit — Level 15 to Level 16

Introduction

Is writeup ka heading Level 15 → Level 16 hai.

Is level mein next level ka password localhost ke port 30001 par running service ko submit karna hai. Difference ye hai ki service normal plain TCP ke bajay SSL/TLS encryption use karti hai.

Isliye simple Netcat command:

nc localhost 30001

sufficient nahi hogi. Humein OpenSSL ka s_client tool use karna hoga:

openssl s_client -connect localhost:30001

Objective

Is level mein humein:

  • bandit15 user se SSH ke through login karna hai.
  • SSL/TLS service ke port 30001 se connect karna hai.
  • Current level ka password secure connection par submit karna hai.
  • Service se next level ka password receive karna hai.
  • bandit16 user se next SSH login karna hai.

SSL Aur TLS Kya Hote Hain?

SSL

SSL ka full form Secure Sockets Layer hai. SSL ek older protocol hai jo network communication ko encrypt karne ke liye design hua tha.

TLS

TLS ka full form Transport Layer Security hai. TLS SSL ka modern successor hai.

Aaj ke systems mein technically TLS use hota hai, lekin log commonly SSL term bhi use karte hain.

SSL/TLS Ka Purpose

SSL/TLS communication ko protect karta hai:

  • Data encryption
  • Server authentication
  • Message integrity

Simple process:

Client  ─── Secure handshake ───>  Server
Client  <── Certificate / keys ─── Server
Client  <──── Encrypted data ────> Server

Is level mein password encrypted SSL/TLS connection ke through service ko bhejna hai.

OpenSSL

OpenSSL Kya Hota Hai?

OpenSSL ek toolkit hai jo cryptography aur SSL/TLS protocols ke saath kaam karti hai.

Iska use in tasks ke liye hota hai:

  • SSL/TLS connections test karna
  • Certificates inspect karna
  • Cryptographic operations
  • Secure services troubleshoot karna
  • Encrypted network connections establish karna

openssl s_client

openssl s_client ek command-line SSL/TLS client hai.

Basic format:

openssl s_client -connect hostname:port

Is level ke liye:

openssl s_client -connect localhost:30001

Command SSL/TLS handshake establish karke interactive encrypted connection open karti hai.

-ign_eof Option

Problem: Connection Close Ya Read Block

Kabhi-kabhi OpenSSL connection ke saath messages dikh sakte hain:

HEARTBEATING

Ya:

read R BLOCK

Iska matlab zaroori nahi ki connection fail ho gaya hai. OpenSSL server ke response ya additional input ka wait kar sakta hai.

-ign_eof Kya Karta Hai?

-ign_eof OpenSSL ko EOF input ko immediately connection close karne ke liye use na karne ke liye kehta hai.

Command:

openssl s_client -connect localhost:30001 -ign_eof

Is level ke liye helpful command:

openssl s_client -connect localhost:30001 -ign_eof

Interactive Input

Connection establish hone ke baad:

  1. Current password type karein.
  2. Enter press karein.
  3. Correct! response ka wait karein.
  4. Next password copy karein.

SSL Certificate Output

OpenSSL connection ke start mein certificate-related information display kar sakta hai:

CONNECTED(00000003)
Can't use SSL_get_servername
depth=0 CN = localhost

CONNECTED

CONNECTED(00000003)

Iska matlab hai ki TCP connection establish ho gaya hai.

Certificate Information

CN = localhost

CN ka meaning Common Name hai. Yahan certificate localhost ke naam se associated hai.

Certificate Warnings

Local challenge services self-signed ya specially configured certificates use kar sakti hain. Certificate warning learning environment mein expected ho sakti hai.

Important point ye hai ki SSL/TLS handshake ke baad encrypted channel establish hua ya nahi.

read R BLOCK Message

read R BLOCK ka meaning generally ye hai ki OpenSSL read operation ke liye wait kar raha hai.

Ye message dekh kar turant Ctrl + C na press karein. Pehle current password type karke Enter press karein.

Helpful command:

openssl s_client -connect localhost:30001 -ign_eof

Agar session stuck lage aur response nahi aa raha ho, to input carefully submit karein.

Alternative Password Pipe Method

Password ko direct pipe ke through bhi send kar sakte hain:

Interactive method beginners ke liye better hai, kyunki SSL output clearly dekh sakte hain aur password accidentally command history mein expose nahi hota.

Common Errors

Connection Refused

Possible reasons:

  • Port 30001 wrong hai.
  • localhost wrong type hua hai.
  • SSL service temporarily unavailable hai.
  • Aapne nc use kiya instead of OpenSSL.

Correct command:

openssl s_client -connect localhost:30001 -ign_eof

HEARTBEATING Ya read R BLOCK

Ye messages connection ke waiting state ko indicate kar sakte hain. Password type karke Enter press karein.

Helpful command:

openssl s_client -connect localhost:30001 -ign_eof

Wrong! Please enter the correct current password

Check karein:

  • Current bandit15 password correct hai.
  • Password ke start ya end mein extra space nahi hai.
  • Uppercase aur lowercase characters same hain.
  • jN2... password ko carefully copy kiya gaya hai.

Password Characters Confuse Ho Rahe Hain

Pasted output mein ye characters similar dikh sakte hain:

0  and O
1  and l

Correct password ko service ke Correct! response se copy karein.

OpenSSL Command Not Found

Check karein:

which openssl

Bandit server par OpenSSL normally available hota hai.

SSH Permission Denied

Next level par login karte waqt check karein:

  • Username bandit16 hai.
  • Port 2220 use ho raha hai.
  • SSL service se mila exact password use ho raha hai.

Correct command:

ssh bandit16@bandit.labs.overthewire.org -p 2220

Security Lessons

Is level se humein ye important lessons milte hain:

  • Plain TCP aur SSL/TLS-encrypted TCP mein difference hota hai.
  • Netcat har encrypted service ke liye sufficient nahi hota.
  • OpenSSL s_client SSL/TLS connections test karne ke liye useful hai.
  • SSL/TLS data ko network transmission ke dauran protect karta hai.
  • Ports specific services identify karte hain.
  • Hostname aur port dono correct hone chahiye.
  • Certificate output server identity ke baare mein information de sakta hai.
  • Password transmission ke liye encrypted channel safer hota hai.
  • Similar-looking characters credentials mein mistakes create kar sakte hain.
