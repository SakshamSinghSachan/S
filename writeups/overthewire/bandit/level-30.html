Introduction

Is writeup ka heading Level 30 → Level 31 hai.

Is level mein bhi humein ek Git repository clone karni hai, lekin is baar README.md file mein sirf message hai: just an epmty file... muahaha

Common Errors

Wrong Port

Port 2220 use karein, 22 nahi.

git clone ssh://bandit30-git@localhost:2220/home/bandit30-git/repo

Wrong Username

Git username bandit30-git hai, bandit30 nahi.

Wrong Password

Git password bandit30 ka password hai (same as current user).

Tags Feature Unknown

Agar aapko Git tags ke baare mein pata nahi hai, to ye level difficult lag sakta hai. Git documentation ya tutorials se tags feature seekh lein.

Tag Name Typo

Tag name exactly same hona chahiye:

git show secret

Incorrect:

git show Secret  # Case-sensitive
git show secrets  # Extra 's'

README.md Par Depend

README.md mein koi useful information nahi hai. Tags check karna zaroori hai.

Security Lessons

Is level se humein ye important lessons milte hain:

  • Git tags mein bhi sensitive information store ho sakta hai.
  • Tags ko lightly ignore nahi karna chahiye.
  • Git repositories ke saare features (commits, branches, tags) audit karne chahiye.
  • Release tags mein version information ke saath changelogs bhi hote hain jo sensitive data contain kar sakte hain.
  • Tags delete karne se bhi purane tags remote repositories mein exist kar sakte hain.
  • Git repositories comprehensively inspect karna important hai.
