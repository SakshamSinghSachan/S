Human-Readable Files

Human-Readable File Kya Hoti Hai?

Human-readable file woh file hoti hai jiska content humans normally read aur understand kar sakte hain.

Example:

This is a normal text file.
Password: example123

Binary Ya Non-Human-Readable File

Binary files machine-oriented data contain karti hain. Unhe directly terminal par display karne par random ya strange characters dikh sakte hain.

Example type:

Binary data

Binary data ke examples:

  • Compiled programs
  • Images
  • Audio files
  • Compressed files
  • Encrypted data

Bandit Level 4 mein mostly files readable text nahi hain. Sirf ek file normal readable text contain karti hai.

Type Meaning Example

Binary Machine-oriented data Program ya image data
Compressed Compressed format mein data ZIP ya GZIP
Encrypted Protected unreadable data Ciphertext

file Command

file Command Kya Karti Hai?

file command kisi file ka type identify karne ki koshish karti hai.

Basic format:

file filename

Example:

file ./-file07

Possible output:

./-file07: ASCII text

ASCII text ka matlab hai ki file normal readable text contain karti hai.

Hyphen Se Start Hone Wale Filenames

Problem Kya Hai?

Files ke naam hyphen se start ho rahe hain:

-file07

Linux commands mein hyphen options ke liye bhi use hota hai.

Example:

ls -l

Yahan -l ek option hai.

Agar aap directly run karein:

cat -file07

To command ise filename ki jagah option samajh sakti hai.

Correct Method: ./

Correct command:

cat ./-file07

Yahan:

.   → Current directory
/   → Path separator
-file07 → Actual filename

./-file07 ka meaning hai:

Current directory ke andar `-file07` naam wali file

Alternative Method: --

Kuch commands -- ko options ke end ke roop mein support karti hain:

cat -- -file07

Iska meaning hai ki -file07 ko option nahi, filename samjho.

Recommended beginner command:

cat ./-file07

Common Errors

cat: invalid option

Wrong command:

cat -file07

Correct command:

cat ./-file07

Alternative:

cat -- -file07

Terminal Messed Up

Agar binary file ko accidentally terminal par print kar diya ho:

reset

Wrong Directory

Current directory check karein:

pwd

Correct directory:

/home/bandit4/inhere

Directly wahan jaane ke liye:

cd /home/bandit4/inhere

file Command Not Found

Bandit environment mein file command normally available hoti hai. Files ko identify karne ke liye recommended command:

file ./-file*

SSH Permission Denied

Check karein:

  • Username bandit5 hai.
  • Port 2220 use ho raha hai.
  • Password exactly copy hua hai.
  • Password ke beginning ya ending mein extra space nahi hai.

Correct command:

ssh bandit5@bandit.labs.overthewire.org -p 2220

Security Lessons

Is level se humein ye important lessons milte hain:

  • Har file normal text file nahi hoti.
  • File type identify karna important hai.
  • Binary data ko directly terminal par print karne se terminal output disturb ho sakta hai.
  • file command file type identify karne mein useful hai.
  • Hyphen se start hone wale filenames ko ./ ya -- ke saath handle karna chahiye.
  • reset terminal recovery ke liye useful command hai.
  • Shell wildcards multiple files ke saath kaam karne mein help karte hain.
  • Sensitive information readable text file mein stored ho sakti hai.
  • CTF challenges mein filtering aur identification important skills hain.
