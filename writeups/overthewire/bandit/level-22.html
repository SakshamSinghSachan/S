OverTheWire Bandit — Level 22 to Level 23

Introduction

Is writeup ka heading Level 22 → Level 23 hai.

Is level mein bhi password ek cron job ke through automatically /tmp directory ki file mein copy ho raha hai.

Difference ye hai ki is baar temporary filename directly script mein fixed nahi hai. Script variables aur MD5 hash ka use karke filename generate karti hai.

Relevant cron file:

cronjob_bandit23

Relevant script:

/usr/bin/cronjob_bandit23.sh

Script ka simplified logic:

myname=$(whoami)
mytarget=$(echo I am user $myname | md5sum | cut -d ' ' -f 1)
cat /etc/bandit_pass/$myname > /tmp/$mytarget

Humein script ko bandit23 ke context mein samajhna hai, kyunki cron job script ko bandit23 user ke roop mein execute karta hai.

Objective

Is level mein humein:

  • bandit22 user se SSH login karna hai.
  • /etc/cron.d/cronjob_bandit23 read karna hai.
  • /usr/bin/cronjob_bandit23.sh script inspect karni hai.
  • Script ke variables ka meaning samajhna hai.
  • bandit23 ke liye exact MD5 hash calculate karna hai.
  • Hash ko temporary filename ke roop mein use karna hai.
  • /tmp se password file read karni hai.
  • bandit23 user se next SSH login karna hai.

Script Explanation

Script:

#!/bin/bash
myname=$(whoami)
mytarget=$(echo I am user $myname | md5sum | cut -d ' ' -f 1)
echo "Copying passwordfile /etc/bandit_pass/$myname to /tmp/$mytarget"

Shebang

Script ko Bash interpreter ke through run karne ke liye use hota hai.

myname Variable

myname=$(whoami)

whoami current user ka username return karta hai.

Script cron ke through bandit23 user ke naam se execute ho rahi hai, isliye:

myname=bandit23

$(command)

Command substitution ka use command ke output ko variable ya larger command ke andar insert karne ke liye hota hai.

Example:

Final hash

md5sum Command

MD5 Hash Kya Hota Hai?

MD5 ek hash function hai jo input data ka fixed-length hexadecimal digest generate karta hai.

Example:

Input: I am user bandit23
Output: 8ca319486bfbbc3663ea0fbe81326349

MD5 output normally 32 hexadecimal characters ka hota hai.

Important: Newline Ka Effect

Script mein command hai:

echo I am user bandit23 | md5sum

Normal echo output ke end mein newline add karta hai. Ye newline hash calculation ka part ban sakti hai.

Isliye script ke exact behavior ko reproduce karne ke liye echo use karein:

echo I am user bandit23 | md5sum

Hash generate karte waqt echo -n use na karein, kyunki usse trailing newline remove ho jayegi aur hash different aa sakta hai.

MD5 Security Note

MD5 modern password storage ke liye secure nahi maana jata. Is level mein MD5 ka use educational purpose ke liye filename generate karne mein ho raha hai.

cut Command

cut Kya Karti Hai?

cut command text ki specific fields ya characters extract karne ke liye use hoti hai.

md5sum ka output generally is format mein hota hai:

8ca319486bfbbc3663ea0fbe81326349  -

Hash aur - ke beech spaces hoti hain. Humein sirf first field chahiye.

-d ' ' Option

-d ' '

Delimiter ko space set karta hai.

-f 1 Option

-f 1

First field select karta hai.

Complete command:

cut -d ' ' -f 1

Correct Command

echo I am user bandit23 | md5sum | cut -d ' ' -f 1

Output:

8ca319486bfbbc3663ea0fbe81326349

Important: Aapke pasted command mein cut -d'' -f 1 formatting error dikh raha hai. Correct form hai:

cut -d ' ' -f 1

Common Errors

Wrong Username Hash Karna

Incorrect input:

echo I am user bandit22 | md5sum | cut -d ' ' -f 1

Script bandit23 ke naam se run hoti hai, isliye correct input hai:

echo I am user bandit23 | md5sum | cut -d ' ' -f 1

echo -n Use Karna

Incorrect for reproducing this script:

echo -n I am user bandit23 | md5sum

Script normal echo use karti hai, jo newline include kar sakti hai. Correct command:

echo I am user bandit23 | md5sum | cut -d ' ' -f 1

Wrong cut Syntax

Incorrect:

cut -d'' -f 1

Correct:

cut -d ' ' -f 1

No Such File or Directory

Check karein:

ls /tmp

Hash dobara calculate karein:

echo I am user bandit23 | md5sum | cut -d ' ' -f 1

Phir exact hash path use karein:

cat /tmp/8ca319486bfbbc3663ea0fbe81326349

Cron File Abhi Update Nahi Hui

Cron job ko run hone ke liye kuch seconds ya ek minute lag sakta hai. Thoda wait karke dobara try karein:

cat /tmp/8ca319486bfbbc3663ea0fbe81326349

Password Copy Error

Password:

QYwBY2aiA672PsMmh9puTQuhoz85yR2G

Check karein:

  • Uppercase aur lowercase characters same hain.
  • 0 aur O ko carefully distinguish karein.
  • Password ke start ya end mein extra space nahi hai.

SSH Permission Denied

Next level par login karte waqt check karein:

  • Username bandit23 hai.
  • Port 2220 use ho raha hai.
  • Temporary file se exact password copy hua hai.

Correct command:

ssh bandit23@bandit.labs.overthewire.org -p 2220

Security Lessons

Is level se humein ye important lessons milte hain:

  • Shell variables dynamic filenames create kar sakti hain.
  • whoami script ke executing user ko identify karta hai.
  • Command substitution $() output ko variable mein store karti hai.
  • Pipes complex command pipelines banane mein useful hain.
  • MD5 hash ko filename ke roop mein use kiya ja sakta hai.
  • Newline hash calculation ko change kar sakti hai.
  • cut command command output se specific field extract karti hai.
  • Cron jobs sensitive data ko predictable temporary files mein copy kar sakti hain.
  • Script ko read karke file path mathematically reproduce kiya ja sakta hai.
  • Weakly designed scheduled scripts information disclosure create kar sakti hain.
