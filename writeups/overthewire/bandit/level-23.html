OverTheWire Bandit — Level 23 to Level 24

Introduction

Is writeup ka heading Level 23 → Level 24 hai.

Is level mein bhi ek program cron ke through automatically run ho raha hai, lekin previous levels se difference ye hai ki humein apna pehla shell script create karna hai.

Cron job ek aisi script execute karti hai jo /var/spool/bandit24/foo/ directory mein present saare scripts ko run karti hai aur phir delete kar deti hai.

Humein:

  1. /etc/cron.d/ directory inspect karni hai.
  2. cronjob_bandit24 file read karni hai.
  3. /usr/bin/cronjob_bandit24.sh script ko understand karna hai.
  4. Ek payload script create karna hai jo bandit24 ka password copy kare.
  5. Script ko /var/spool/bandit24/foo/ mein place karna hai.
  6. Cron job ke execute hone ka wait karna hai.
  7. Output file se password read karna hai.

Script Explanation

Script Read Karna

cat /usr/bin/cronjob_bandit24.sh

Script content:

#!/bin/bash
myname=$(whoami)
cd /var/spool/$myname/foo
echo "Executing and deleting all scripts in /var/spool/$myname/foo:"
for i in * ; do
if [ "$i" != "." -a "$i" != ".." ];
then
echo "Handling $i"
owner="$(stat --format "%U" ./$i)"
if [ "${owner}" = "bandit23" ]; then
timeout -s 9 60 ./$i
fi
rm -f ./$i
done
fi

Script Logic Breakdown

  1. Shebang: #!/bin/bash → Bash interpreter use hoga.
  2. Variable: myname=$(whoami) → Current user ka naam store karega.
  3. Directory Change: cd /var/spool/$myname/foo → Target directory mein jaayega.
  4. Loop: for i in * → Directory ke saare files iterate karega.
  5. Condition: if [ "$i" != "." -a "$i" != ".." ] → Current aur parent directory ko skip karega.
  6. Owner Check: if [ "${owner}" = "bandit23" ] → Sirf bandit23 ke owned scripts execute karega.
  7. Execute: timeout -s 9 60 ./$i → Script ko 60 seconds timeout ke saath run karega.
  8. Delete: rm -f ./$i → Execute hone ke baad script delete kar dega.

Key Observations

  • Script bandit24 user ke roop mein run hoti hai.
  • Directory hai: /var/spool/bandit24/foo/
  • Sirf bandit23 ke owned scripts execute honge.
  • Execute hone ke baad scripts delete ho jayengi.
  • Isliye humein apna script bandit23 ke ownership mein create karna hoga.

Common Errors

Wrong Directory

Script ko /var/spool/bandit24/foo/ mein hi create karna hai. Other directories mein script execute nahi hogi.

Missing Executable Permission

Agar chmod +x nahi kiya, to script execute nahi hogi.

chmod +x /var/spool/bandit24/foo/payload.sh

Wrong Owner

Script bandit23 ke ownership mein honi chahiye. Agar aap bandit23 user se login hain aur script create kar rahe hain, to automatically sahi owner set ho jayega.

Script Jaldi Check Karna

Cron ko execute hone mein thoda time lagta hai. Kam se kam 1 minute wait karein.

Output File Empty Hai

Agar /tmp/dollarboysushil empty hai, to:

  • Script correctly create hui hai check karein.
  • Executable permissions verify karein.
  • Thoda aur wait karein.
  • Script dobara create karein.

Password Copy Error

  • Uppercase aur lowercase characters same hain.
  • 0 aur O ko carefully distinguish karein.
  • Password ke start ya end mein extra space nahi hai.

Security Lessons

Is level se humein ye important lessons milte hain:

  • Cron jobs arbitrary scripts execute kar sakti hain.
  • World-writable directories mein malicious scripts place kiye ja sakte hain.
  • Script execution se pehle owner verification important hai.
  • Auto-delete mechanism forensic analysis ko difficult bana sakta hai.
  • Shell scripts create karna automation ka powerful tool hai.
  • /tmp directory temporary data storage ke liye useful hai.
  • Executable permissions chmod +x se set hoti hain.
  • Cron misconfiguration privilege escalation enable kar sakta hai.
  • First shell script create karna beginner ke liye important milestone hai.
