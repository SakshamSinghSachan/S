find Command

find Command Kya Karti Hai?

find command directories ke andar files aur folders search karne ke liye use hoti hai.

Basic format:

find path conditions

Example:

find . -type f

Iska meaning hai:

Current directory se search start karo
Sirf regular files show karo

find subdirectories ke andar bhi automatically search karti hai. Is process ko recursive search kehte hain.

Current Directory: .

Command mein starting dot:

.

current directory ko represent karta hai.

Example:

find .

ka meaning hai:

Current directory aur uske andar ki subdirectories mein search karo.

-type f

-type f

Sirf regular files ko select karta hai.

Ye directories ko result se exclude karta hai.

Example:

find . -type f

-size 1033c

-size 1033c

Exactly 1033 bytes ki files search karta hai.

Yahan:

1033 → Required size
c    → Bytes

Important examples:

-size 1033c   # Exactly 1033 bytes
-size +1033c  # 1033 bytes se badi
-size -1033c  # 1033 bytes se chhoti

Is level mein exact size chahiye, isliye use karein:

-size 1033c

-readable

-readable

Aisi files select karta hai jo current user ke liye readable hain.

Readable permission ka matlab hai ki current user file ko read kar sakta hai. Ye zaroori nahi ki file ka content human-readable text hi ho.

Isliye content ka type verify karne ke liye file command bhi use kar sakte hain.

! -executable

! -executable

Iska meaning hai:

Jo file executable nahi hai

Yahan ! logical NOT operator hai. Ye -executable condition ko reverse karta hai.

-executable       → Executable files
! -executable     → Non-executable files

Complete Search Command

All given conditions ke saath command:

find . -type f -readable -size 1033c ! -executable

Aapke provided command ka short version:

find . -type f -size 1033c

Short command size aur file type filter karti hai, lekin complete challenge conditions ke liye recommended command ye hai:

find . -type f -readable -size 1033c ! -executable

Human-Readable File Ko Verify Karna

-readable ka meaning permission ke context mein readable hota hai. Human-readable text verify karne ke liye result par file command run kar sakte hain.

find . -type f -readable -size 1033c ! -executable -exec file {} \;

Possible output:

./some-directory/some-file: ASCII text

ASCII text ya UTF-8 Unicode text normal human-readable content ko indicate karta hai.

Simple approach:

find . -type f -size 1033c ! -executable

Result mein jo file path mile, usse file command se check karein:

file ./path/to/found-file

Phir content read karein:

cat ./path/to/found-file

Permissions Aur Executable Files

Executable File Kya Hoti Hai?

Executable file woh file hoti hai jise program ki tarah run kiya ja sakta hai.

Linux permissions mein executable permission ko x character se represent kiya jata hai.

Example:

-rwxr-xr-x

Ismein x ka matlab executable permission hai.

Non-Executable File

Non-executable file mein executable permission nahi hoti.

Example:

-rw-r--r--

Is permission string mein x present nahi hai.

ls -l Se Permissions Check Karna

ls -l ./path/to/file

Example:

-rw-r----- 1 bandit6 bandit5 1033 Oct 5 06:19 file

Is line mein x nahi hai, isliye file executable nahi hai.

File Size Samajhna

Linux file size bytes mein measure kar sakta hai.

File size check karne ke liye:

ls -l filename

Ya:

stat filename

find mein exact byte size filter karne ke liye c suffix use hota hai:

-size 1033c

Iska meaning hai:

Exactly 1033 bytes

Recursive Search

Recursive Search Kya Hoti Hai?

Recursive search ka matlab hai current directory ke saath uske andar ki subdirectories mein bhi search karna.

Directory structure example:

inhere/
├── maybehere00/
│   ├── file1
│   └── file2
├── maybehere01/
│   └── file3
└── maybehere02/
    └── file4

Command:

find . -type f

Ye inhere ke andar sabhi subdirectories mein files search karegi.

-exec Option

find ke results par doosri command run karne ke liye -exec use hota hai.

Example:

find . -type f -exec file {} \;

Yahan:

-exec  → Har result par command execute karo
file   → File type identify karo
{}     → Current found file ka placeholder
\;     → -exec command ka end

Challenge ke conditions ke saath:

find . -type f -size 1033c ! -executable -exec file {} \;

Agar output bahut zyada ho, to readable text ko identify karne ke liye output inspect karein.

Common Errors

find: paths must precede expression

Agar command galat format mein likhi gayi ho, to error aa sakta hai.

Correct command:

find . -type f -size 1033c ! -executable

find type f size 1033c Ka Problem

Ye command incomplete hai:

find type f size 1033c

Correct syntax mein options ke aage hyphen aur starting path dono hone chahiye:

find . -type f -size 1033c

Complete command:

find . -type f -readable -size 1033c ! -executable

! History Expansion Problem

Kuch shells mein ! special character hota hai. Agar problem aaye, to ! ko escape kar sakte hain:

find . -type f -readable -size 1033c \! -executable

Bash mein history expansion issue hone par single quotes bhi use kiye ja sakte hain, lekin is simple command mein escaped form sufficient hai.

Wrong Directory

SSH Permission Denied

  • Port 2220 use ho raha hai.

Security Lessons

Is level se humein ye important lessons milte hain:

  • Manual search ke bajay conditions ke basis par automated search ki ja sakti hai.
  • find recursive file discovery ke liye powerful command hai.
  • File type, size aur permissions search filters ban sakte hain.
  • -type f directories ko exclude karta hai.
  • -size 1033c exact byte size match karta hai.
  • ! -executable executable files ko exclude karta hai.
  • -readable current user ke read permission ko check karta hai.
  • file command human-readable content verify karne mein useful hai.
  • -exec ke through ek command ka result doosri command ko diya ja sakta hai.
  • Automation cybersecurity aur system administration mein important skill hai.
