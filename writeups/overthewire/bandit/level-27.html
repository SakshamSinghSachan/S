Key features:

  • Changes track karta hai.
  • Multiple users collaborate kar sakte hain.
  • Previous versions restore kar sakte hain.

Git Clone

git clone command ek remote repository ko local machine par copy karta hai.

Basic syntax:

git clone <repository-url>

Is level mein:

SSH Port Specification

Default SSH Port

Default SSH port 22 hota hai, lekin OverTheWire Bandit 2220 port use karta hai.

Port Specify Karna

Git SSH URL mein port specify karne ka format:

ssh://user@host:port/path/to/repo

Is level mein:

ssh://bandit27-git@localhost:2220/home/bandit27-git/repo

Common Mistake

Query mein port 2228 likha hai, jo incorrect hai. Correct port 2220 hai.

Incorrect:

git clone ssh://bandit27-git@localhost:2228/home/bandit27-git/repo

Correct:

git clone ssh://bandit27-git@localhost:2220/home/bandit27-git/repo

Common Errors

Wrong Port

Port 2220 use karein, 2228 nahi.

Incorrect:

git clone ssh://bandit27-git@localhost:2228/home/bandit27-git/repo

Correct:

git clone ssh://bandit27-git@localhost:2220/home/bandit27-git/repo

Wrong Username

Git username bandit27-git hai, bandit27 nahi.

Wrong Password

Git password bandit27 ka password hai (same as current user).

File Name Case Sensitivity

Linux file names case-sensitive hote hain. README aur Readme different files hain.

Incorrect:

cat Readme  # File not found

Correct:

cat README

Directory Not Found

Agar cd repo fail ho raha hai, to check karein:

  • Clone successfully complete hua hai.
  • Current directory mein repo folder exist karta hai.
ls -la

SSH Host Key Warning

First time connect karne par ye warning normal hai:

The authenticity of host '[localhost]:2220' can't be established.

yes type karke continue karein.

Permission Denied

Agar /home/bandit27/.ssh create nahi ho pa raha, to ye normal hai. Connection phir bhi work karega.

Security Lessons

Is level se humein ye important lessons milte hain:

  • Git repositories sensitive information contain kar sakti hain.
  • SSH authentication secure remote access provide karta hai.
  • Port specification important hai custom SSH setups mein.
  • Version control systems mein passwords accidentally commit ho sakte hain.
  • File names case-sensitive hote hain Linux par.
  • Git clone remote repositories ko local copy karta hai.
  • SSH host key verification security feature hai.
  • Temporary directories (/tmp) safe working space provide karte hain.
