Base64 Kya Hota Hai?

Base64 Encoding

Base64 ek encoding technique hai jo binary ya text data ko printable ASCII characters mein convert karti hai.

Base64 output mein commonly ye characters use hote hain:

A-Z
a-z
0-9
+
/
=

= character padding ke liye use ho sakta hai.

Example:

Original text: Hello
Base64 text:  SGVsbG8=

Encoding Aur Decoding

Encoding

Readable data ko encoded format mein convert karna:

Readable data → Base64 encoded data

Decoding

Encoded data ko original readable form mein convert karna:

Base64 encoded data → Original readable data

Is level mein humein decoding karni hai.

Base64 Encryption Nahi Hai

Base64 encryption nahi hai.

Base64 data ko koi bhi easily decode kar sakta hai agar usse pata ho ki data Base64 format mein hai.

Difference:

Concept Meaning
Encoding Data representation change karna
Decoding Encoded data ko original form mein lana
Encryption Secret key ke through data protect karna
Decryption Key ke through encrypted data recover karna

Base64 security protection provide nahi karta. Password ko Base64 mein store karna secure password storage nahi hai.

base64 Command

Decode Karna

Base64 data decode karne ka command:

base64 --decode

Short option:

base64 -d

Dono commands same kaam karti hain.

File Directly Decode Karna

Aap file ko directly decode bhi kar sakte hain:

base64 --decode data.txt

Ya:

base64 -d data.txt

Pipe Ke Through Decode Karna

Aapke solution mein:

cat data.txt | base64 --decode

Process:

cat data.txt
      ↓
Base64 encoded content
      ↓
      |
      ↓
base64 --decode
      ↓
Original readable text

--decode Aur -d

Long form:

base64 --decode

Short form:

base64 -d

Beginner-friendly command:

cat data.txt | base64 --decode

Short command:

base64 -d data.txt

Pipe |

Pipe first command ke output ko second command ke input mein send karta hai.

cat data.txt | base64 --decode

Yahan:

cat data.txt       → Encoded data output karta hai
|                  → Output ko next command ko bhejta hai
base64 --decode    → Encoded data decode karta hai

Direct method pipe ke bina:

base64 --decode data.txt

Dono methods valid hain.

Newline Aur Padding

Base64 output ke end mein = characters padding represent kar sakte hain:

Cg==

File ke decoded output ke end mein newline bhi ho sakti hai. Terminal par output ke baad cursor next line par aa sakta hai. Newline password ka part nahi hoti.

Common Errors

Invalid Input

Agar file Base64 format mein nahi hai ya content incorrectly copied hai, to error aa sakta hai:

base64: invalid input

Check karein:

cat data.txt

File ke complete content ko modify kiye bina decode karein:

base64 --decode data.txt

base64: command not found

Agar command available nahi hai, to system mein Base64 utility installed nahi ho sakti. Bandit server par ye command normally available hoti hai.

Password Mein Extra Text Copy Karna

Decoded output:

The password is 6zPeziLdR2RKNdNYFNb6nVCKzphlXHBM

Actual password sirf ye hai:

6zPeziLdR2RKNdNYFNb6nVCKzphlXHBM

The password is phrase ko include na karein.

Password Copy Error

Password:

6zPeziLdR2RKNdNYFNb6nVCKzphlXHBM

Check karein:

  • Uppercase aur lowercase characters same hain.
  • 0 aur O ko carefully distinguish karein.
  • Password ke start ya end mein extra space nahi hai.

SSH Permission Denied

Next level par login karte waqt check karein:

  • Username bandit11 hai.
  • Port 2220 use ho raha hai.
  • Sirf decoded password enter kiya gaya hai.

Correct command:

ssh bandit11@bandit.labs.overthewire.org -p 2220

Security Lessons

Is level se humein ye important lessons milte hain:

  • Base64 encoding encryption nahi hoti.
  • Encoded data ko correct decoder se original form mein convert kiya ja sakta hai.
  • base64 --decode Base64 content decode karta hai.
  • Pipe commands ko combine karne ke liye useful hai.
  • File extension ya content ko inspect karke data format identify karna important hai.
  • Password ko decode karne ke baad output mein surrounding text ko ignore karna chahiye.
  • Base64 passwords ko secure storage method nahi samajhna chahiye.
  • Encoding aur encryption ka difference cybersecurity mein important hai.
