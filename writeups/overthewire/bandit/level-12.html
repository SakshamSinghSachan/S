Temporary Directory

/tmp Directory Kya Hoti Hai?

Linux mein /tmp temporary files aur temporary working directories ke liye use hoti hai.

Bandit challenge ke liye /tmp useful hai kyunki:

  • Aap apne working files rakh sakte ho.
  • Original data.txt ko modify nahi karna padta.
  • Intermediate compressed files ko organize kar sakte ho.
  • Different users ke home directories ko disturb nahi karte.

mkdir Command

mkdir ka full form make directory hai.

Directory create karne ke liye:

mkdir /tmp/dbs

Yahan:

mkdir       → Directory create karta hai
/tmp/dbs    → New directory ka complete path

Unique Temporary Directory

Shared system par unique directory name use karna better hota hai:

mkdir /tmp/myname123

Ya:

mkdir /tmp/bandit12-work

Aapke solution mein directory hai:

/tmp/dbs

Directory Mein Jaana

cd /tmp/dbs

Current location check karein:

pwd

Expected output:

/tmp/dbs

cp Command

cp Kya Karti Hai?

cp ka full form copy hai. Ye file ki duplicate copy create karti hai.

data.txt ko temporary directory mein copy karne ke liye:

cp data.txt /tmp/dbs

Agar aap already /tmp/dbs mein ho aur original file home directory mein hai:

cp ~/data.txt .

Yahan:

~/data.txt → Home directory ki data.txt file
.          → Current directory

Copy Verify Karna

ls

Expected output:

data.txt

xxd Aur Hexdump

Hexdump Kya Hota Hai?

Hexdump kisi file ke raw bytes ko hexadecimal representation mein display karta hai.

Example:

00000000: 1f8b 0808 7a3c 6565 0203 6461 7461 2e62  ....z<ee..data.b

Hexadecimal values machine-level bytes ko represent karti hain. Humans ke liye raw binary data ko directly understand karna difficult hota hai.

xxd Command

xxd file ka hexadecimal dump create kar sakti hai aur hexdump ko reverse karke original binary file bhi bana sakti hai.

Hexdump display karne ke liye:

xxd data.txt

Hexdump ko original binary file mein convert karne ke liye:

xxd -r data.txt data

Yahan:

xxd    → Hexdump utility
-r     → Reverse operation
 data.txt → Hexdump input
 data   → Reconstructed binary output

xxd -r Ka Meaning

xxd -r data.txt data

ka meaning hai:

data.txt ke hexadecimal bytes ko reverse karke data naam ki binary file banao.

Important:

data.txt → Hexdump text
 data    → Reconstructed binary file

Filename Rename Karna

Agar output file ka naam data hai, to uska type extension ke basis par nahi, content ke basis par identify hoga.

file data

file Command

File Type Identify Karna

file data

file command actual file content ke signatures aur structure ko inspect karke type identify karti hai.

Possible outputs:

data: gzip compressed data
data: bzip2 compressed data
data: POSIX tar archive (GNU)
data: ASCII text

Har Step Par file Run Karna

Repeated compression challenge ka main technique hai:

file current_file

Phir output ke according correct extraction command choose karein.

Workflow:

file → Correct decompression command → file → Next command

Compression Formats

Gzip

Gzip files commonly .gz extension ke saath hoti hain.

File ko gzip ke through decompress karne ke liye:

gzip -d file.gz

Short form:

gunzip file.gz

Agar current file ka naam data hai aur file data output gzip show karta hai, to pehle rename karein:

mv data file.gz

Phir decompress karein:

gzip -d file.gz

Bzip2

Bzip2 files commonly .bz2 extension ke saath hoti hain.

Decompress command:

bzip2 -d file.bz2

Short form:

bunzip2 file.bz2

Agar file file output bzip2 show karta hai:

mv file file.bz2
bzip2 -d file.bz2

Tar Archive

Tar archive multiple files ko ek archive mein store karta hai. Tar khud compression nahi hota, lekin gzip ya bzip2 ke saath combine ho sakta hai.

Tar archive extract karne ke liye:

tar xf file.tar

Yahan:

x → Extract
f → Archive file specify karna

Tar list dekhne ke liye:

tar tf file.tar

Tar archive create karne ke liye generally -c use hota hai, lekin is level mein humein extraction karni hai.

mv Command

mv Kya Karti Hai?

mv ka full form move hai. Iska use file move ya rename karne ke liye hota hai.

Example:

mv data file.gz

Yahan file location same hai, isliye mv rename ka kaam karegi.

data → file.gz

Rename Kyun Zaroori Hai?

Compression commands usually extension ke basis par nahi, content ke basis par kaam kar sakti hain, lekin correct extension use karna clarity aur tool compatibility ke liye useful hai.

Example:

mv data file.gz
gzip -d file.gz

Repeated Decompression Workflow

Har iteration mein ye steps follow karein:

1. file current_file
2. Output format identify karo
3. Zaroorat ho to mv se correct extension do
4. Correct decompression command run karo
5. ls se new file dekho
6. New file par file command run karo
7. Repeat karo

Example workflow:

file data
mv data file.gz
gzip -d file.gz
file file

Agar output bzip2 aaye:

mv file file.bz2
bzip2 -d file.bz2
file file

Agar output tar aaye:

mv file file.tar
tar xf file.tar
ls

Common Errors

Bandit environment mein xxd normally available hota hai. Command verify karein:

which xxd

gzip: file.gz: unknown suffix

Correct extension ke saath rename karein:

mv data file.gz
gzip -d file.gz

bzip2: not a bzip2 file

Decompress karne se pehle type check karein:

file file

Agar output bzip2 nahi hai, to bzip2 command use na karein.

tar: This does not look like a tar archive

Archive ka type verify karein:

file file

Tar archive hone par:

mv file file.tar
tar xf file.tar

File exists

Agar /tmp/dbs already exist karta hai, to new directory banayein:

mkdir /tmp/dbs2

Security Lessons

Is level se humein ye important lessons milte hain:

  • Hexdump raw binary data ka textual representation hota hai.
  • xxd -r hexdump ko original binary file mein convert karta hai.
  • File extension ke bajay file command se actual type identify karna chahiye.
  • Gzip, Bzip2 aur Tar different formats hain.
  • Har compression format ke liye different extraction command ho sakti hai.
  • Repeated compression ko step by step reverse karna hota hai.
  • /tmp safe temporary workspace ke liye useful hota hai.
  • Original challenge file ki copy par work karna better practice hai.
  • file command har extraction ke baad next action decide karne mein help karti hai.
  • Unknown files ko blindly execute ya open nahi karna chahiye.
