Binary Files Aur Printable Strings

Binary File Kya Hoti Hai?

Binary file aisi file hoti hai jisme machine-oriented data stored hota hai. Is data ko directly terminal par read karna difficult ho sakta hai.

Binary files ke examples:

  • Compiled programs
  • Images
  • Audio files
  • Compressed files
  • Database files
  • Encrypted data

data.txt naam hone ke baad bhi file ke andar binary data ho sakta hai. File extension hamesha actual content type guarantee nahi karti.

Human-Readable String Kya Hoti Hai?

Human-readable string printable characters ka sequence hota hai, jaise:

hello
password123
G7w8LIi6J3kTb8A7j9LgrywtEUlyyp6s

Binary file ke andar kuch normal text strings hidden ho sakti hain. Humein unhi strings mein password find karna hai.

strings Command

strings Kya Karti Hai?

strings command binary file ke andar se printable character sequences extract karti hai.

Basic format:

strings filename

Is level ke liye:

strings data.txt

Ye binary file ke andar milne wali human-readable strings ko terminal par print karegi.

strings Kyun Use Karni Hai?

Agar hum run karein:

cat data.txt

To binary bytes ki wajah se output unreadable ya terminal ke liye confusing ho sakta hai.

Instead:

strings data.txt

binary content mein se readable text extract karega.

strings Ka Output

Output mein normal words, random-looking strings aur symbols aa sakte hain:

random text
abc123
==== secret-looking-line
more data

Humein us line ko find karna hai jiske beginning mein multiple equal signs hain.

grep Command

grep Kya Karti Hai?

grep command input ya file ke andar specific text pattern search karti hai.

Basic format:

grep pattern filename

Pipe ke saath:

command1 | grep pattern

Equal Sign Search

Extracted strings mein equal sign search karne ke liye:

strings data.txt | grep '='

Ye un lines ko display karega jinmein = character present hai.

Several Equal Signs Search

Clue mein several equal signs diye gaye hain. One or more equal signs ke liye regular expression use kar sakte hain:

strings data.txt | grep -E '=+'

Yahan:

-E  → Extended regular expression enable karta hai
=   → Equal sign match karta hai
+   → Previous pattern one or more times match karta hai

Beginning Mein Equal Signs Search

Agar equal signs line ke beginning mein hon, to:

strings data.txt | grep -E '^=+'

Yahan:

^    → Line ka beginning
=+   → One or more equal signs

Lekin actual file output mein equal signs ke pehle spaces ya other characters ho sakte hain. General search ke liye ye command safer hai:

strings data.txt | grep '='

Regular Expression Basics

^

^ regular expression mein line ke beginning ko represent karta hai.

Example:

grep '^hello' file.txt

Ye un lines ko match karega jo hello se start hoti hain.

$

$ line ke end ko represent karta hai.

Example:

grep 'world$' file.txt

Ye un lines ko match karega jo world par end hoti hain.

+

+ ka meaning one or more occurrences hota hai.

Example:

grep -E '=+' file.txt

Ye one ya multiple equal signs ko match karega.

=

= normal literal character hai. Isse directly search karne ke liye:

grep '='

Provided Command Ko Samajhna

Aapne command use ki:

strings data.txt | grep '^'

Is command ke parts:

Part Meaning
strings data.txt Binary file se printable strings extract karta hai
| First command ka output second command ko deta hai
grep Pattern search karta hai
'^' Har line ke beginning ko match karta hai

^ har line ke beginning par present hota hai, isliye grep '^' mostly every non-empty extracted line ko show kar sakta hai.

Password locate karne ke liye better commands:

strings data.txt | grep '='

Ya:

strings data.txt | grep -E '=+'

Pipe |

Pipe first command ka standard output second command ke standard input mein send karta hai.

strings data.txt | grep '='

Process:

strings data.txt
        ↓
Printable strings
        ↓
        |
        ↓
grep '='
        ↓
Equal sign wali lines

Common Errors

data.txt: No Such File

Check karein:

pwd
ls

Aap bandit9 ki home directory mein hone chahiye.

grep '^' Se Bahut Saara Output Aa Raha Hai

Ye normal hai. ^ line ke beginning ko match karta hai, isliye ye almost all lines display kar sakta hai.

Password filter karne ke liye use karein:

strings data.txt | grep '='

grep '=' Se Multiple Lines Aa Rahi Hain

Clue ke according woh line select karein jo:

  • Human-readable ho.
  • Several = characters se preceded ho.
  • Password-like random string contain karti ho.

More specific command:

strings data.txt | grep -E '^=+'

Agar spaces ya other characters equal signs se pehle hon, to general command use karein:

strings data.txt | grep '='

Password Copy Error

Password:

G7w8LIi6J3kTb8A7j9LgrywtEUlyyp6s

Check karein:

  • Uppercase aur lowercase characters same hain.
  • 0 aur O ko carefully distinguish karein.
  • Password ke start ya end mein extra space nahi hai.

SSH Permission Denied

Next level par login karte waqt check karein:

  • Username bandit10 hai.
  • Port 2220 use ho raha hai.
  • Password exactly copy hua hai.

Correct command:

ssh bandit10@bandit.labs.overthewire.org -p 2220

Security Lessons

Is level se humein ye important lessons milte hain:

  • Binary files ke andar printable text strings hidden ho sakti hain.
  • strings binary data se readable sequences extract karti hai.
  • grep extracted output ko filter kar sakti hai.
  • Regular expressions text patterns search karne mein useful hain.
  • ^ line beginning ko represent karta hai.
  • + one or more occurrences ko represent karta hai.
  • Pipe multiple commands ko chain karta hai.
  • File extension se actual content type hamesha confirm nahi hota.
  • Binary files ko directly cat karne ke bajay strings use karna better ho sakta hai.
