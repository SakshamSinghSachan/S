OverTheWire Bandit — Level 28 to Level 29

Introduction

Is writeup ka heading Level 28 → Level 29 hai.

Is level mein bhi humein ek Git repository clone karni hai, lekin is baar README.md file mein password censored (XXXXXXXXXX) hai. Humein Git ke version control features ka use karke password recover karna hai.

Git commit history mein purane commits check karne se humein wo version mil sakta hai jisme password abhi censored nahi tha.

Humein:

  • Git repository clone karni hai.
  • README.md file inspect karni hai.
  • Commit history check karni hai.
  • Purane commit mein password find karna hai.

Commit Messages Analysis

Commit messages se clues mil sakti hain:

  • initial commit of README.md → Pehla commit, original content

  • fix info leak → Information leak fix hua (password censored)

Git Checkout

Checkout Command

git checkout command se hum kisi specific commit par switch kar sakte hain.

Basic syntax:

git checkout <commit-hash>

Detached HEAD State

Jab hum kisi specific commit par checkout karte hain (branch par nahi), to Git "detached HEAD" state mein chala jata hai.

Warning message:

Note: switching to 'f08b9cc...'.
You are in 'detached HEAD' state. You can look around, make experimental changes and commit them, and you can discard any commits you make in this state without impacting any branches by switching back to a branch.

Iska matlab:

  • Hum files inspect kar sakte hain.
  • Changes temporary honge.
  • Wapas branch par jaane se ye changes discard ho jayenge.

Common Errors

Wrong Port

Port 2220 use karein, 22 nahi.

git clone ssh://bandit28-git@localhost:2220/home/bandit28-git/repo

Wrong Username

Git username bandit28-git hai, bandit28 nahi.

Wrong Password

Git password bandit28 ka password hai (same as current user).

Wrong Commit Hash

Commit hash carefully copy karein. Ek character bhi wrong hua to checkout fail hoga.

Correct:

git checkout f08b9cc63fa1a4602fb665257633c2dae6e5651b

Detached HEAD Confusion

Detached HEAD state mein ghabrayein nahi. Ye normal hai jab hum specific commit par checkout karte hain.

Wapas master branch par jaane ke liye:

git checkout master

Password Copy Error

Password:

tQKvmcwNYcFS6vmPHIUSI3ShmsrQZKBS

Check karein:

  • Uppercase aur lowercase characters same hain.
  • 0 aur O ko carefully distinguish karein.
  • Password ke start ya end mein extra space nahi hai.

SSH Permission Denied

Next level par login karte waqt check karein:

  • Username bandit29 hai.
  • Port 2220 use ho raha hai.
  • README.md se exact password copy hua hai.
ssh bandit29@bandit.labs.overthewire.org -p 2220

Security Lessons

Is level se humein ye important lessons milte hain:

  • Git commit history mein sensitive data permanently store ho sakta hai.
  • Password censored karne se purane commits mein data recover ho sakta hai.
  • Git repositories mein secrets commit nahi karne chahiye.
  • Commit history sanitize karna important hai before making repository public.
  • git filter-branch ya git filter-repo se history sanitize ki ja sakti hai.
  • Version control systems mein data deletion permanent nahi hota.
  • Git hooks aur pre-commit checks sensitive data leaks prevent kar sakte hain.
  • Environment variables aur secrets management tools use karne chahiye.
