OverTheWire Bandit — Level 19 to Level 20

Introduction

Is writeup ka heading Level 19 → Level 20 hai.

Is level mein home directory ke andar ek special binary file di gayi hai:

bandit20-do

Ye ek setuid binary hai. Iska purpose hai kisi command ko doosre user ke privileges ke saath execute karna.

Normal bandit19 user directly ye file read nahi kar sakta:

/etc/bandit_pass/bandit20

Lekin bandit20-do binary command ko bandit20 user ke effective privileges ke saath run karti hai. Isliye hum is binary ka use karke password file read kar sakte hain.

Main command:

./bandit20-do cat /etc/bandit_pass/bandit20

Found password:

Objective

Is level mein humein:

  • bandit19 user se SSH ke through login karna hai.
  • bandit20-do binary identify karni hai.

  • id command se effective user ID verify karni hai.
  • bandit20-do ke through password file read karni hai.
  • bandit20 user se next SSH login karna hai.

Setuid Kya Hota Hai?

UID Kya Hota Hai?

UID ka full form User ID hai. Linux internally users ko numeric IDs ke through identify karta hai.

Example:

uid=11019(bandit19)

Iska meaning:

UID number: 11019
Username:   bandit19

EUID Kya Hota Hai?

EUID ka full form Effective User ID hai.

EUID determine karta hai ki process ko currently kis user ke permissions mil rahe hain.

Normally real UID aur effective UID same hote hain:

uid=11019(bandit19) euid=11019(bandit19)

Setuid program ke case mein dono different ho sakte hain:

uid=11019(bandit19) euid=11020(bandit20)

Yahan process start bandit19 ne kiya, lekin effective permissions bandit20 ki hain.

Setuid Bit

Setuid ka full form Set User ID upon execution hai.

Agar kisi executable file par setuid bit enabled ho, to file execute karne wala program file owner ke privileges ke saath run ho sakta hai.

Is level mein:

Binary owner: bandit20
Current user: bandit19
Effective user: bandit20

Setuid Permission Format

Setuid file permissions mein owner execute position par s character dikh sakta hai.

Example:

-rwsr-x---

Yahan s setuid bit ko represent karta hai.

File permissions check karne ke liye:

ls -l bandit20-do

Setuid Ka Security Risk

Setuid programs powerful hote hain kyunki low-privileged user higher-privileged operation perform kar sakta hai.

Agar setuid program user input ko safely handle na kare, to security vulnerability create ho sakti hai.

Real systems par setuid binaries ko carefully audit kiya jata hai.

bandit20-do Binary

Binary Ka Purpose

bandit20-do ek wrapper program hai jo command ko bandit20 ke effective user privileges ke saath run karti hai.

Bina arguments ke execute karein:

./bandit20-do

Output:

Run a command as another user.
Example: /bandit20-do id

Is output se humein binary ka expected usage samajh aata hai:

./bandit20-do command

./ Ka Meaning

.   → Current directory

Isliye:

./bandit20-do

ka meaning hai:

Current directory ke andar bandit20-do executable run karo.

Linux security reasons ki wajah se current directory automatically command search path mein include nahi hoti. Isliye binary run karne ke liye ./ likhna padta hai.

id Command

id Kya Karti Hai?

id command current user ki identity aur group information display karti hai.

id

Setuid binary ke through:

./bandit20-do id

Output:

uid=11019(bandit19) gid=11019(bandit19) euid=11020(bandit20) groups=11019(bandit19)

Output Breakdown

Part Meaning
uid=11019(bandit19) Original user jisne process start kiya
gid=11019(bandit19) Original primary group
euid=11020(bandit20) Effective user permissions
groups=11019(bandit19) User ke groups

Important observation:

Real user:      bandit19
Effective user: bandit20

Yahi setuid behavior ka proof hai.

Password File Read Karna

Direct Access Problem

bandit19 user ke roop mein direct command:

cat /etc/bandit_pass/bandit20

permission denied de sakti hai, kyunki file bandit20 user ke liye protected hai.

Setuid Binary Ke Through Access

Correct command:

./bandit20-do cat /etc/bandit_pass/bandit20

Command ke parts:

./bandit20-do              → Setuid wrapper
cat                        → Execute hone wali command
/etc/bandit_pass/bandit20  → Protected password file

Binary cat ko bandit20 ke effective privileges ke saath execute karwati hai.

Output:

Security Lessons

Is level se humein ye important lessons milte hain:

  • Setuid binaries doosre user ke effective privileges mein run ho sakti hain.
  • Real UID aur effective UID alag ho sakte hain.
  • id command identity aur privilege context verify karne ke liye useful hai.
  • Protected files ko access karne ke liye user permissions important hoti hain.
  • Setuid programs security-sensitive hote hain.
  • Untrusted input ko setuid programs mein safely handle karna zaroori hai.
  • ls -l permissions aur ownership inspect karne ke liye useful hai.
  • Binary wrapper ka behavior execute karke samjha ja sakta hai.
  • Privilege escalation concepts ko authorized labs mein hi practice karna chahiye.
