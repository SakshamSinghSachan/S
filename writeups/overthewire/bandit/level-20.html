OverTheWire Bandit — Level 20 to Level 21

Introduction

Is writeup ka heading Level 20 → Level 21 hai.

Is level mein home directory ke andar ek setuid binary hai:

suconnect

Ye binary localhost ke us port se connect karti hai jo hum command-line argument ke roop mein provide karte hain.

Process:

  1. suconnect localhost ke specified port se connect hoti hai.
  2. Port se ek line of text read karti hai.
  3. Received text ko current bandit20 password se compare karti hai.
  4. Password correct hone par bandit21 ka next password send karti hai.

Humein is level mein ek Netcat listener create karna hoga jo current password send karega.

Objective

Is level mein humein:

  • bandit20 user ke do SSH sessions open karne hain.
  • Pehle session mein Netcat listener start karna hai.
  • Listener ko current bandit20 password file se input dena hai.
  • Doosre session mein ./suconnect ko same port ke saath run karna hai.
  • suconnect ko listener se connect karwana hai.
  • Next level ka password receive karna hai.
  • bandit21 user se next SSH login karna hai.

Given Information

Current level:

Username: bandit20
Password: Previous level se mila password

Setuid binary:

suconnect

Example port:

1234

Password file:

/etc/bandit_pass/bandit20

Next username:

bandit21

Provided next password:

NvEJF7oVjkddltPSrdKEFOllh9V1IBcq

Password Note: Listener ko current bandit20 password send karna hai. Current password aur next password ko confuse na karein. Current password previous level se mila hota hai; suconnect correct input ke baad next password return karti hai.

suconnect Binary

suconnect Kya Karti Hai?

suconnect ek setuid helper binary hai jo:

  • Localhost ke specified TCP port se connect karti hai.
  • Connection se ek line read karti hai.
  • Us line ko bandit20 password se compare karti hai.
  • Match hone par next password send karti hai.

Basic syntax:

./suconnect port

Example:

./suconnect 1234

Usage Check Karna

Bina argument ke run karein:

./suconnect

Program usage information display kar sakti hai.

Netcat Listener

Listener Kya Hota Hai?

Listener ek network program hota hai jo specified port par incoming connection ka wait karta hai.

Netcat ke through listener create karne ke liye:

nc -l 1234

Yahan:

nc → Netcat
-l → Listen mode
1234 → Listening port

File Se Password Send Karna

Current password file ko listener ke standard input mein redirect karne ke liye:

nc -l 1234 < /etc/bandit_pass/bandit20

Iska meaning:

/etc/bandit_pass/bandit20 ka content
        ↓
Netcat listener ka input
        ↓
Port 1234 par connect hone wale client ko send

Input Redirection <

Shell mein < input redirection operator hai.

command < file

Iska meaning hai:

File ka content command ke standard input ke roop mein use karo.

Example:

cat < /etc/bandit_pass/bandit20

Bandit challenge mein:

nc -l 1234 < /etc/bandit_pass/bandit20

Netcat ko password file ka content input ke roop mein milta hai.

Two-Terminal Technique

Do Connections Kyun Chahiye?

Ek terminal mein listener ko running rehna hai. Doosre terminal se suconnect run karna hai.

Isliye do separate SSH sessions use karna easiest hai.

Diagram:

Terminal 1: bandit20
        ↓
nc listener on port 1234
        ↑
        ↓
Terminal 2: bandit20
        ↓
./suconnect 1234

Terminal 1

ssh bandit20@bandit.labs.overthewire.org -p 2220

Phir:

nc -l 1234 < /etc/bandit_pass/bandit20

Terminal 2

Doosra SSH connection open karein:

ssh bandit20@bandit.labs.overthewire.org -p 2220

Phir:

./suconnect 1234

Connection Flow

Terminal 1
nc listener port 1234
        ↑
        │ TCP connection
        │

Listener current password send karta hai. suconnect password verify karke next password return karti hai.

Localhost Aur TCP Port

Localhost

localhost current machine ko represent karta hai.

Common IPv4 address:

127.0.0.1

suconnect same Bandit machine par port 1234 se connect karti hai.

TCP Port

Port ek numbered communication endpoint hota hai.

Is level mein:

Listener port: 1234
Client:        suconnect

Dono commands mein same port number hona chahiye:

nc -l 1234
./suconnect 1234

Agar port numbers different honge, to connection establish nahi hoga.

Setuid Concept

suconnect setuid binary hai. Iska matlab hai ki ye owner ke effective privileges ke saath execute ho sakti hai.

File permissions check karne ke liye:

ls -l suconnect

Setuid permission mein execute position par s character dikh sakta hai:

-rwsr-x---

Is level mein main focus networking aur data flow par hai, lekin suconnect ka setuid behavior bhi important hai.

Complete Walkthrough

Step 1: Terminal 1 Mein Login Karein

ssh bandit20@bandit.labs.overthewire.org -p 2220

Password prompt par previous level ka password enter karein.

Step 2: Listener Start Karein

Terminal 1 mein:

nc -l 1234 < /etc/bandit_pass/bandit20

Ye command port 1234 par listen karegi aur client connection ka wait karegi.

Terminal ko close na karein.

Step 3: Terminal 2 Mein Same User Se Login Karein

Doosra terminal open karein:

ssh bandit20@bandit.labs.overthewire.org -p 2220

Step 4: suconnect Run Karein

Terminal 2 mein:

./suconnect 1234

suconnect localhost ke port 1234 par connect karegi.

Step 5: Password Verification Dekhein

Agar listener ne correct current password send kiya, to output aa sakta hai:

Read: CURRENT_BANDIT20_PASSWORD
Password matches, sending next password

Next password suconnect ke output mein display hoga:

NvEJF7oVjkddltPSrdKEFOllh9V1IBcq

Step 6: Password Copy Karein

NvEJF7oVjkddltPSrdKEFOllh9V1IBcq

Step 7: bandit21 Par Login Karein

ssh bandit21@bandit.labs.overthewire.org -p 2220

Password enter karein:

NvEJF7oVjkddltPSrdKEFOllh9V1IBcq

Alternative Method: echo

Password file redirect karne ke bajay echo se current password send kar sakte hain:

echo 'CURRENT_BANDIT20_PASSWORD' | nc -l 1234

Lekin password ko manually type karne ke bajay password file se read karna better hai:

nc -l 1234 < /etc/bandit_pass/bandit20

Netcat Options

-l

-l

Listen mode enable karta hai.

-p

Kuch Netcat versions mein port specify karne ke liye:

nc -l -p 1234

use kiya jata hai.

Modern versions mein ye bhi kaam kar sakta hai:

nc -l 1234

Agar pehla syntax work na kare, to doosra try karein:

nc -l -p 1234 < /etc/bandit_pass/bandit20

Port Busy Error

Agar port already in use ho:

Address already in use

To different unused port choose karein, jaise:

nc -l 2345 < /etc/bandit_pass/bandit20

Doosre terminal mein same port use karein:

./suconnect 2345

Common Errors

Connection Refused

Possible reasons:

  • Listener start nahi hua.
  • Port numbers different hain.
  • Listener terminal close ho gaya.
  • Port already blocked ya unavailable hai.

Check karein:

nc -l 1234 < /etc/bandit_pass/bandit20

Aur doosre terminal mein:

./suconnect 1234

Password Does Not Match

Check karein ki listener current bandit20 password send kar raha hai:

cat /etc/bandit_pass/bandit20

Correct listener command:

nc -l 1234 < /etc/bandit_pass/bandit20

Next password ko listener mein send na karein. Listener ko current password send karna hai.

Wrong Port

Listener:

nc -l 1234

Client:

./suconnect 1234

Dono commands mein port same hona chahiye.

suconnect: No Such File

Current directory check karein:

pwd
ls

Aapko home directory mein suconnect binary dikhni chahiye.

Run karein:

./suconnect 1234

Netcat Syntax Problem

Agar ye command work na kare:

nc -l 1234 < /etc/bandit_pass/bandit20

To try karein:

nc -l -p 1234 < /etc/bandit_pass/bandit20

Password Copy Error

Next password:

NvEJF7oVjkddltPSrdKEFOllh9V1IBcq

Similar characters carefully check karein:

0 vs O
1 vs l

Security Lessons

Is level se humein ye important lessons milte hain:

  • Network services client-server model par kaam karti hain.
  • Netcat simple TCP listener create kar sakta hai.
  • Ek process listener hota hai aur doosra process client.
  • Input redirection file content ko network service ko send kar sakti hai.
  • localhost same machine par network communication ke liye use hota hai.
  • Ports client aur server ko connect karte hain.
  • Setuid binaries privileged network operations kar sakti hain.
  • Current password aur next password ko confuse nahi karna chahiye.
  • Two-terminal technique networking challenges mein useful hoti hai.
