Duplicate Aur Unique Lines

Duplicate Line Kya Hoti Hai?

Duplicate line woh line hoti hai jo file mein ek se zyada baar present ho.

Example:

apple
banana
apple

Yahan apple duplicate line hai kyunki woh do baar appear ho rahi hai.

Unique Line Kya Hoti Hai?

Unique line woh line hoti hai jo file mein exactly ek baar appear hoti hai.

Example:

apple
banana
apple
orange

Is example mein banana aur orange unique lines hain.

Bandit Level 8 mein humein woh line find karni hai jo exactly once appear hoti hai.

sort Command

sort Kya Karti Hai?

sort command text lines ko alphabetical ya lexicographical order mein arrange karti hai.

Basic command:

sort data.txt

Ye data.txt ki lines ko sorted order mein terminal par display karegi.

Sorting Kyun Zaroori Hai?

uniq command normally adjacent duplicate lines ko identify karti hai. Agar same line file mein alag-alag locations par scattered ho, to uniq unhe duplicate ke roop mein correctly identify nahi kar payegi.

Example unsorted data:

apple
banana
orange
apple

Yahan dono apple lines adjacent nahi hain.

Sort karne ke baad:

apple
apple
banana
orange

Ab duplicates adjacent ho gaye hain aur uniq unhe correctly process kar sakti hai.

sort Output Save Nahi Karti

By default:

sort data.txt

Original data.txt file ko change nahi karti. Sorted result terminal par display hota hai.

uniq Command

uniq Kya Karti Hai?

uniq command repeated adjacent lines ko filter, remove ya report karti hai.

Basic command:

uniq data.txt

Lekin accurate duplicate processing ke liye input ko pehle sort karna better hai:

sort data.txt | uniq

uniq -u

uniq -u

-u ka meaning unique hai.

Ye sirf woh lines display karta hai jo exactly ek baar occur hoti hain. Repeated lines ko output se remove kar deta hai.

uniq -c

uniq -c

Har line ke occurrences ka count show karta hai.

Example:

2 apple
1 banana
2 orange

Ye option analysis ke liye useful hai.

uniq -d

uniq -d

Sirf duplicate lines display karta hai.

Pipe |

Pipe Kya Hota Hai?

Pipe symbol:

|

Pipe first command ke output ko second command ke input mein send karta hai.

General format:

command1 | command2

Is Level Mein Pipe

sort data.txt | uniq -u

Process:

sort data.txt
       ↓
Sorted lines
       ↓
       |
       ↓
uniq -u
       ↓
Only line occurring once

Complete Solution Methods

Method 1: Recommended Pipe Method

sort data.txt | uniq -u

Output:

EN632PlfViZbn3PhVK3XOGSLNInNE00t

Method 2: Temporary Sorted File

Pehle sorted output ko new file mein save karein:

sort data.txt > sorted.txt

Phir unique line find karein:

uniq -u sorted.txt

Method 3: Count Lines

Occurrences count karne ke liye:

sort data.txt | uniq -c

Output mein jis line ke saamne count 1 ho, woh password line hai.

Method 4: sort -u Se Difference

sort -u data.txt

Ye duplicate lines ko remove karke har different line ka ek copy show karta hai. Lekin ye sirf distinct lines show karta hai; ye specifically only-once occurring lines ko isolate nahi karta.

Is challenge ke liye correct command hai:

sort data.txt | uniq -u

Common Errors

uniq -u Se Multiple Lines Aa Rahi Hain

Possible reason hai ki input pehle sorted nahi hai.

Incorrect:

uniq -u data.txt

Correct:

sort data.txt | uniq -u

uniq repeated lines ko identify karne ke liye adjacent lines par depend karti hai. sort duplicates ko ek saath group karta hai.

data.txt: No Such File

Check karein:

pwd
ls

Aap bandit8 ki home directory mein hone chahiye:

/home/bandit8

Password Copy Error

Password:

EN632PlfViZbn3PhVK3XOGSLNInNE00t

Check karein:

  • Uppercase aur lowercase characters correct hain.
  • 0 aur O ko carefully distinguish karein.
  • Password ke start ya end mein extra space nahi hai.

SSH Permission Denied

Next level par login karte waqt check karein:

  • Username bandit9 hai.
  • Port 2220 use ho raha hai.
  • Password exact copy hua hai.

Correct command:

ssh bandit9@bandit.labs.overthewire.org -p 2220

Security Lessons

Is level se humein ye important lessons milte hain:

  • Large text files mein repeated aur unique lines identify ki ja sakti hain.
  • sort data ko ordered format mein arrange karta hai.
  • uniq repeated lines ko process karta hai.
  • uniq -u only-once occurring lines display karta hai.
  • uniq ko correct results ke liye generally sorted input chahiye.
  • Pipe multiple commands ko combine karta hai.
  • uniq -c frequency analysis ke liye useful hai.
  • Log analysis aur data processing mein sort aur uniq commonly use hote hain.
  • Command chaining Linux automation ka important part hai.
