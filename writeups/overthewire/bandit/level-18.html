.bashrc Kya Hoti Hai?

.bashrc File

.bashrc ek shell configuration file hoti hai jo Bash interactive shell start hone par load ho sakti hai.

Is file mein commonly ye settings hoti hain:

  • Aliases
  • Environment variables
  • Shell prompt configuration
  • Functions
  • Startup commands
  • Custom shell behavior

File ka common location:

~/.bashrc

Yahan ~ current user ki home directory ko represent karta hai.

Modified .bashrc

Is challenge mein .bashrc ko intentionally modify kiya gaya hai. Iska purpose ye hai ki normal SSH login par shell user ko logout kar de.

Normal flow:

SSH Login
    ↓
Bash Shell Start
    ↓
.bashrc Execute
    ↓
Logout Command
    ↓
Connection Close

Logout Kyon Hota Hai?

Jab SSH interactive shell start karta hai, Bash startup configuration read kar sakti hai. Agar .bashrc mein logout ya exit command ho, to shell immediately close ho sakti hai.

Isliye prompt nahi milta:

bandit18@bandit:~$

Pseudo-Terminal Kya Hota Hai?

Terminal

Terminal ek interface hai jisme user commands type karta hai aur output dekhta hai.

Pseudo-Terminal

Pseudo-terminal, ya PTY, ek software-based terminal interface hota hai jo remote shell ko interactive terminal jaisa behavior provide karta hai.

SSH normally interactive login ke waqt pseudo-terminal allocate kar sakta hai.

Pseudo-Terminal Allocation Disable Karna

SSH ka -T option pseudo-terminal allocation disable karta hai.

ssh -T user@host

Iska meaning:

Remote session ke liye pseudo-terminal allocate mat karo.

Is level mein -T use karne se normal interactive shell behavior avoid hota hai aur hum remote command execute kar sakte hain.

SSH -T Option

Correct Command

ssh -T bandit18@bandit.labs.overthewire.org -p 2220

Important: Aapke pasted command mein ssh - bandit18... dikh raha hai. Correct option -T hai, sirf - nahi.

-T Ka Benefit

-T ke saath SSH pseudo-terminal allocate nahi karta. Isse humein interactive prompt ke bina remote command run karne ka option milta hai.

Example:

ssh -T bandit18@bandit.labs.overthewire.org -p 2220 cat readme

Remote Command Execution

SSH Command Ke Baad Remote Command

SSH syntax:

ssh [options] user@host [remote-command]

Example:

ssh -T bandit18@bandit.labs.overthewire.org -p 2220 cat readme

Is command mein:

ssh -T ... → Remote server se non-interactive connection
cat readme → Remote server par execute hone wali command

Command Ka Flow

Local terminal
      ↓
SSH connection
      ↓
Remote bandit18 account
      ↓
cat readme execute
      ↓
Password output local terminal par

Quotes Ke Saath Remote Command

Remote command ko quotes mein bhi likh sakte hain:

ssh -T bandit18@bandit.labs.overthewire.org -p 2220 'cat readme'

Quotes command ko ek complete remote command ke roop mein preserve karti hain.

Interactive Aur Non-Interactive Shell

Interactive Shell

Interactive shell mein user ko prompt milta hai aur commands manually type kar sakta hai.

Example:

bandit18@bandit:~$

Non-Interactive Shell

Non-interactive shell mein command pehle se provide hoti hai aur output return hone ke baad session close ho sakta hai.

Example:

ssh -T bandit18@bandit.labs.overthewire.org -p 2220 cat readme

Is level mein non-interactive command execution useful hai kyunki interactive shell .bashrc ke logout behavior se affected hoti hai.

Common Errors

ssh - Aur ssh -T Mein Difference

Incorrect ya incomplete:

Correct:

ssh -T bandit18@bandit.labs.overthewire.org -p 2220

-T ek complete SSH option hai.

Connection Immediately Close Ho Raha Hai

Security Lessons

Is level se humein ye important lessons milte hain:

  • SSH interactive aur non-interactive sessions support karta hai.
  • .bashrc shell startup behavior control kar sakti hai.
  • Malicious ya modified startup files login behavior change kar sakti hain.
  • -T pseudo-terminal allocation disable karta hai.
  • SSH ke through remote command directly execute ki ja sakti hai.
  • Har login ke liye interactive shell zaroori nahi hoti.
  • Remote command execution troubleshooting mein useful hoti hai.
  • Shell startup files ko security analysis mein inspect karna important hai.
